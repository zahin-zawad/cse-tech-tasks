## About This Project

An AI-powered sales and order assistant for Facebook Pages. It understands Bangla, English and Banglish, answers using real shop data, takes and confirms orders, brings back lost customers with offers and free-delivery alerts, and hands over to a human when needed.

## What Is New in Version 3

Version 3 explains **exactly how each feature works**. Compared with the earlier version:

- Every feature has an ID (F01 to F28) and is described with the same structure: purpose, trigger, how it works step by step, rules, example, and what happens if something goes wrong.
- The path of a single message through the system is explained step by step ([02](02_System_Overview.md)).
- The order process is defined as clear steps with validation rules ([05](05_Features_Orders_and_Fulfilment.md)).
- The sales features (lost-sale tracking, win-back alerts, follow-ups) have clear triggers, conditions and limits ([06](06_Features_Sales_Intelligence_and_Engagement.md)).
- Four end-to-end scenarios show everything working together ([09](09_End_to_End_Scenarios.md)).
- Each phase lists its features, what is not included, and a "Done When" checklist.
