## About This Project

An AI-powered sales and order assistant for Facebook Pages. It understands Bangla, English and Banglish, answers using real shop data, takes and confirms orders, brings back lost customers with offers and free delivery alerts, and hands over to a human when needed.

The documentation is split into separate files so each topic is easy to read and manage. The project is divided into **four phases**. Each phase produces a working system, so progress is safe even if time runs short.
